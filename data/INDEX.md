# EnemyForge Knowledge Base & Data Catalog

Centralized reference data, preset definitions, base game fallback files, encounter mappings, and localization files.

| Path / File | Purpose |

| `item.msgbnd.dcx` | Bundled Elden Ring message archive for FMG lookups. |
| `item_dlc01.msgbnd.dcx` | Shadow of the Erdtree DLC message archive for DLC items. |
