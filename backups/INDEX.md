# EnemyForge Backups Directory

Stores timestamped pre-write regulation snapshots (`regulation.bin.bak_YYYYMMDD_HHMMSS`) and the pristine base game vanilla fallback snapshot (`regulation.bin.vanilla_fallback`) with SHA-256 verification.

Provides 1-click restore and `--rollback` functionality to instantly revert the game's regulation file to pristine condition.
